## 🚀 HOW TO USE

### ✅ Currently Running (Local)

**Access the website:** http://localhost:8000

**Stop the server:** Press Ctrl+C in the terminal

**Restart the server:**
```powershell
cd website
node server.js
```

### 🌍 Deploy to the World (Choose One)

#### **OPTION 1: GitHub Pages (Recommended - Free, Easy, Automatic)**

1. Go to: https://github.com/mandativamshidhar/multimedia-streaming
2. Click: Settings → Pages
3. Select: main branch, /website folder
4. Click: Save
5. Wait: 1-2 minutes
6. Your site: https://mandativamshidhar.github.io/multimedia-streaming

**To update**: Just push changes to GitHub:
```bash
git add website/
git commit -m "Update website"
git push origin main
```

#### **OPTION 2: Netlify (Free, Auto-Deploy)**

1. Visit: https://netlify.com
2. Click: New site from Git
3. Select: Your GitHub repository
4. Set: Publish directory = website
5. Deploy!

**Benefits**: Auto-deploys on push, custom domains, analytics

#### **OPTION 3: Vercel (Free, Global CDN)**

1. Visit: https://vercel.com
2. Import: Your GitHub repository
3. Set: Root directory = website
4. Deploy!

**Benefits**: Global CDN, automatic SSL, one-click rollbacks

#### **More Options** (See DEPLOYMENT_GUIDE.md):
- Docker (Containerized)
- AWS S3 + CloudFront (Scalable)
- Firebase Hosting (Google's Platform)
- Traditional Web Hosting (cPanel/Plesk)
