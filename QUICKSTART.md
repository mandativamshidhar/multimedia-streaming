# Quick Start Guide

## View the Website Locally

### Option 1: Using Python (Recommended if installed)
```bash
cd website
python -m http.server 8000
```

Then open: http://localhost:8000

### Option 2: Using Node.js
```bash
cd website
node server.js
```

Then open: http://localhost:8000

### Option 3: Using PowerShell
```powershell
cd website
# Using built-in web server (Windows 10+)
python -m http.server 8000
```

## Deploy to GitHub Pages

Your website is ready to deploy! GitHub Pages will automatically serve it at:
**https://mandativamshidhar.github.io/multimedia-streaming**

### Steps:
1. Ensure code is committed and pushed to GitHub
2. Go to repository Settings → Pages
3. Select `main` branch and `/website` folder
4. Click Save
5. Wait 1-2 minutes for deployment
6. Your site is live! 🎉
