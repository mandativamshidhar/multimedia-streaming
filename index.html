Key Features

🌐

Dual Network Stack

TCP for reliable control/data transmission and UDP for low-latency media streaming with non-blocking I/O.

📹

Video Codec (H.264)

Industry-standard H.264 video encoding with support for I/P/B frames, sequence numbering, and timestamps.

🔊

Audio Codec (AAC)

Advanced Audio Codec support with multiple sample rates and bitrate configurations.

⚡

Low Latency

Non-blocking I/O, circular frame buffers, and atomic counters for real-time performance.

🔄

Parallel Processing

Parallel video/audio processing with multithreading and background receive thread.

💾

Smart Buffering

Thread-safe circular frame buffer with configurable sizes and automatic packet queuing.

Technical Specifications

Video Configuration

  • Resolution: Up to 4K (3840×2160)
  • Frame Rate: 1-60 FPS
  • Bitrate: 100kbps - 50Mbps
  • Codec: H.264/AVC

Audio Configuration

  • Sample Rates: 8kHz - 48kHz
  • Channels: Mono or Stereo
  • Bitrate: 32kbps - 320kbps
  • Codec: AAC

Network Configuration

  • TCP Port: Configurable (default 5000)
  • UDP Port: Configurable (default 5001)
  • Buffer Size: Configurable (default 65536 bytes)
  • Max Queued: Configurable (default 100 packets)

Getting Started

1. Clone the Repository

git clone https://github.com/mandativamshidhar/multimedia-streaming.git
cd multimedia-streaming

2. Build the Project

Windows (PowerShell):

mkdir build
cd build
cmake ..
cmake --build . --config Release
.\bin\Release\streaming_app.exe

Linux/macOS:

mkdir -p build
cd build
cmake ..
cmake --build . -- -j$(nproc)
./bin/streaming_app

3. Basic Usage

#include "streaming/engine.h"

multimedia::streaming::StreamingEngine engine(
    multimedia::streaming::StreamingMode::SENDER
);

// Initialize with server IP and ports
engine.initialize("192.168.1.100", 5000, 5001);

// Configure video: 1920x1080 @ 30fps, 5Mbps
engine.configureVideo(1920, 1080, 30, 5000000);

// Configure audio: 44.1kHz stereo, 128kbps
engine.configureAudio(44100, 2, 128000);

// Send frames
engine.sendVideoFrame(rgbData, dataSize);
engine.sendAudioFrame(audioData, sampleCount);

// Get statistics
auto stats = engine.getStatistics();
