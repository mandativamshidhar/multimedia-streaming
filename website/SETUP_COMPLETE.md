## 🚀 Quick Start

### Test Locally

The server is already running! Open your browser:
```
http://localhost:8000
```

Or start manually:
```bash
cd website
node server.js
```

### Deploy to GitHub Pages (Free & Easy)

1. Go to your GitHub repository settings
2. Navigate to Pages section
3. Select `main` branch and `/website` folder
4. Click Save
5. Your site will be at: https://mandativamshidhar.github.io/multimedia-streaming
