## Step-by-Step (Simple English)

### Step 1: Tell GitHub You Want a Shelf
Go to: **https://github.com/new**

This takes you to GitHub's "create repository" page. Think of it as claiming your space on the bookshelf.

### Step 2: Name Your Shelf
Fill in:
- **Name:** `multimedia-streaming`
- **Make it:** Public (so everyone can see it)
- **Description:** Anything you want (we suggest: "Professional C++ multimedia streaming library")

### Step 3: GitHub Creates Your Shelf
Click "Create repository"

GitHub makes an empty folder/space for your code. It's like the librarian preparing a spot for your book.

### Step 4: Put Your Books on the Shelf
In PowerShell, run:
```powershell
cd "C:\Users\manda\Git_projects\Project"
git push -u origin main
```

This uploads all your code to GitHub. It's like putting your finished book on the shelf.

### Step 5: Celebrate!
Visit: **https://github.com/mandativamshidhar/multimedia-streaming**

You'll see your code there! Share this link with everyone.
